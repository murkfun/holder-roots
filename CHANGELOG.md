# Changelog

Releases are GitHub Releases of this repository (tag `v<version>`): `murkfun-holders-<version>.tgz`, the same file as
`murkfun-holders.tgz` (the stable URL below) and `SHA256SUMS`. Install or update the latest release with

```bash
npm install -g https://github.com/murkfun/holder-roots/releases/latest/download/murkfun-holders.tgz
```

## 1.0.0

First release of the holder set toolkit for `MurkFunHolderRoots` on BNB Smart Chain mainnet. Targets the MurkFun
contracts v1.1 (holder set `0xD59867DADC96202284Fa54d016C6d66a0adBaE24`).

- `murkfun-holders tree`: rebuild the whole tree from the `Batch` events and compare every root with the contract's.
- `murkfun-holders lookup`: one holder (0x address, name or name.ai) with its batch, position, status and verified
  Merkle path.
- `murkfun-holders audit`: diff the set with the SPACE ID registry (listed non-holders, admin-minted entries, missing
  holders).
- `murkfun-holders challenge` / `enqueue`: fraud proofs and forced inclusions (dry run unless `--key-file` and
  `--yes`; only on chain 56, below `--max-gas-price-gwei`, and a dispute deposit only up to `--max-deposit`).
- `murkfun-holders status` (including the owner, the operator, `MIN_BOND` and `DISPUTE_DEPOSIT`) and the bytecode check
  of the deployed contracts against `contracts/` (`npm run verify-bytecode`); `scripts/build-verifier.sh` rebuilds
  `BatchVerifier.sol` from `circuits/batch`.
- The same code as a library (`murkfun-holders`, `/tree`, `/chain`, `/lookup`, `/audit`, ...).
